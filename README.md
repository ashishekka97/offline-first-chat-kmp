# Echo (KMP)

An offline-first Kotlin Multiplatform chat application.

## Architecture
* **Shared UI:** Jetpack Compose (Android) & SwiftUI (iOS)
* **Local Database:** Room Multiplatform (SQLite)
* **Dependency Injection:** Koin
* **Build System:** Gradle (Version Catalogs)

## Setup
1. Clone the repository.
2. Open in Android Studio (Ladybug or newer recommended).
3. Sync Project with Gradle Files.
4. Run the `androidApp` configuration or open `iosApp/iosApp.xcworkspace` in Xcode.
